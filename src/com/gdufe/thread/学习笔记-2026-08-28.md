# 学习笔记 · 2026-08-28（多线程：创建 / join / 竞态 / synchronized）

## 1. 线程是什么

- 线程 = 独立执行路径；main 自己是主线程
- CPU 只有一个脑子，靠**时间片**快速切换伺候多条线——并发是「假象」
- 进程 = 一个程序；线程 = 程序里的多条线（两只手）
- 后端意义：同时服务多个用户，一个卡住不堵死其他

## 2. 创建：永远用 Runnable

```java
class Worker implements Runnable {
    public void run() { /* 要干的活 */ }
}
Thread t = new Thread(new Worker());
t.start();   // 开新线程，JVM 在里面调 run()
```

| | extends Thread | implements Runnable |
|--|----------------|---------------------|
| 单继承限制 | 用完就没 | 还留着继承名额 |
| 工程惯例 | 不用 | **永远用它** |

- **start() vs run()**：start 开新线程；run 是普通调用（输出立刻变整齐）——面试必考
- 输出交错、每次顺序不同 = 并发本质，不是 bug

## 3. join：等待

```java
t1.join();   // 当前线程（如 main）原地等 t1 结束
```

- 不 join：main 的收尾抢跑（「全部干完」先打印）
- JVM 规矩：所有非守护线程结束，程序才退出
- `public static void main(String[] args) throws InterruptedException` ——受检异常初识

## 4. 竞态条件（线程不安全）

- `i++` = 读 → 加 → 写，三步之间线程切换插入 → 互相踩、丢更新
- 实测四次：13249 / 20000 / 14002 / 14768——**有时对有时错，随机性是最阴险的**：跑一次对了 ≠ 安全
- 面试词：竞态条件（race condition）

## 5. synchronized：锁

```java
static synchronized void add() { count++; }   // static 的锁 = 类对象（RaceDemo.class）
```

- **锁的是对象**：同一时刻只有拿到锁的线程进临界区，其他排队
- 两个线程必须抢**同一把锁**；`synchronized (new Object())` 每次新锁 = 没锁
- 锁的代码越短越好（只锁一行，不锁循环）
- 面试词：**互斥**（一个进）、**原子性**（中间不可插）、**临界区**（被锁保护的代码）

## 6. 报错对照表新增

| 报错 | 含义 |
|------|------|
| NoClassDefFoundError | 编译期没事，**运行时**某个类的字节码加载不出来（如内部类 $Worker.class 丢失） |

- 内部类编译出独立 .class：`外部$内部.class`（RaceDemo$Worker、匿名类 $1）
- .class 是二进制，永远别在编辑器打开/保存
