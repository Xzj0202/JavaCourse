## 1. XOR 三性质（136 正解）

```
a ^ a = 0        a ^ 0 = a        交换律 + 结合律
```

- 全异或一遍：成对的全抵消成 0，剩下单身数字
- 结果变量初始化为 0（0 是异或的「白板」）
- 344 的 XOR 换位是炫技；136 里它是**标准答案**

```java
int ans = 0;
for (int num : nums) ans ^= num;
return ans;
```

## 2. HashMap 计数（169）

```java
Map<Integer, Integer> freq = new HashMap<>();
for (int num : nums) {
    freq.put(num, freq.getOrDefault(num, 0) + 1);   // 取不到返 0，省判空
}
for (int num : freq.keySet()) {                      // keySet+get：好读
    if (freq.get(num) > nums.length / 2) return num;
}
```

- **`getOrDefault(key, 默认值)`**：计数神器；用 `get` 首次取到 null 再 +1 会空指针
- 遍历两种：
  - `keySet()` + `get(key)` —— 简单好读，多一次哈希查找
  - `entrySet()` + `Map.Entry<Integer, Integer> e` —— `e.getKey()/e.getValue()`，少一次查找
- 彩蛋：169 有 O(1) 空间「摩尔投票法」，面试高频

## 3. git log 分页器与自查口诀

- `git log` 长输出进入分页器（less）：**`q` 退出**、空格下一页、`b` 上一页
- `git log --oneline`：一行一条，短输出不进分页器
- **`origin/main` 标在哪个 commit 上 → 云端就推到了哪里**（`(HEAD -> main, origin/main)` 同标 = 已同步）
- 自查口诀：**`git log` 查「交没交」，`git status` 第一行查「推没推」**
