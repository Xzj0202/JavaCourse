# 学习笔记 2026-10-13 · lesson24（MySQL 安装与连接）

## 一、MySQL 是什么结构

**客户端—服务端**模型：

| 角色 | 具体是什么 | 状态 |
|---|---|---|
| 服务端 | `mysqld`，注册成 Windows 服务 `MySQL80`，开机自启、常驻后台 | 一直跑 |
| 客户端 | 插件（Database Client）、终端 `mysql` 命令、以后的 JDBC 程序 | 用的时候才连 |

**关键认知：插件断开 ≠ 数据库停了。** 客户端关的只是一条会话通道，跟"挂掉电话 ≠ 公司倒闭"一样。

## 二、安装要点

1. 安装包：`mysql-installer-community-8.0.xx.msi`（https://dev.mysql.com/downloads/installer/）
2. Setup Type 选 **Server only** —— 别选 Developer Default（会顺带装 Workbench + 示例库，浪费时间）
3. Accounts and Roles：设 root 密码，**字母+数字**，不要中文和特殊字符
4. Configure as Windows Service 保持勾选，服务名 `MySQL80`
5. 看到整页绿色打勾才算装完

## 三、客户端连接

### 插件

- 主插件：**Database Client**（发布者 cweijan）
- 配套：**Database Client JDBC**（提供 JDBC 连接能力，同一个作者，两个一起装）

### 连接参数

| 项 | 值 |
|---|---|
| 主机 | `127.0.0.1`（别写 localhost，可能解析到 IPv6 导致超时） |
| 端口 | `3306` |
| 用户名 | `root` |
| 密码 | 装 MySQL 时设的 |
| 数据库 | 留空（连的是服务器本身，不是某个库） |

### 连接表单里三个字段的区别 ★

| 字段 | 是什么 | 打个比方 |
|---|---|---|
| **名称** | 这条连接在本地的**标签**，只给自己看，改名不影响连接 | 通讯录里的**备注名** |
| **用户名/密码** | 真正的**登录账户**，服务端认的东西 | 对方的**手机号** |
| **分组** | 左侧树里的文件夹，用来归类多条连接（支持两级） | 通讯录的**分组** |

## 四、左侧树怎么看

```
local                                  ← 连接（名称）
├── Security                           ← 【账号权限】文件夹，不是数据库
│   └── Users
│       ├── mysql.infoschema@localhost ┐
│       ├── mysql.session@localhost    │ MySQL 自带的 4 个【账户】
│       ├── mysql.sys@localhost        │ 不是库！
│       └── root@localhost             ┘ 你登录用的就是它
└── mysql                              ← 【数据库】系统库之一
    ├── Query                          ┐
    ├── Tables (38)                    │ 插件的【分类节点】
    ├── Views                          │ 不是数据，用来展开分类
    ├── Functions                      │
    └── Procedures                     ┘
```

- **默认隐藏系统库**：`information_schema` / `performance_schema` / `sys` 不显示（设置里搜 `system` 可开）
- **账户 ≠ 数据库**，这两件事今天混过一次

## 五、★ GUI 是视图，SQL 是事实

> **左侧树显示的是"插件想给你看的"，`SHOW DATABASES;` 查的才是"服务器里真实存在的"。**

树上没有的表 ≠ 数据库里没有。以后排查问题会反复用到这个区别。

## 六、查询窗口的两条规则

1. **光标停在哪条语句上，就执行哪条**（不是执行整个文件）。真实工作里一个 `.sql` 文件几百行，这是好事。
2. **`;` 是语句分隔符**，客户端靠它切分语句。漏了分号会把两条粘成一条报错。

## 七、工程约定（今天定的）

| 东西 | 放哪 | 性质 |
|---|---|---|
| **正式 SQL** | 项目里 `src/com/gdufe/db/lessonN/` | 你的资产，进 Git |
| **临时试手** | 插件的查询窗口（`C:\Users\Xzj\.dbclient\query\`） | 草稿，不进 Git，跑完就丢 |

- 文件名写**这个脚本干什么**：`create-database.sql` ✅ / `test.sql` ❌
- 插件的 `Edit Connection` 用来改密码/端口，不用删了重建

## 八、报错对照表

| 报错 | 原因 | 解决 |
|---|---|---|
| `Can't connect to MySQL server on '127.0.0.1' (10061)` | 服务没启动 | `Win+R` → `services.msc` → 启动 `MySQL80` |
| `Access denied for user 'root'@'localhost'` | 密码错 | Edit Connection 改密码 |
| `Client does not support authentication protocol` | 驱动太老，不认 MySQL 8 的 `caching_sha2_password` | 换 SQLTools，或更新插件 |
| `ERROR 1007 ... database exists` | 重复建同名库 | 换个名字，或先 `DROP` |
| `ERROR 1050 ... Table already exists` | 重复建同名表 | 先 `DROP TABLE`（危险操作，想清楚再敲） |
