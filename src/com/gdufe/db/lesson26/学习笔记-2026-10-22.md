# 学习笔记 2026-10-22 · lesson26（DML 增删改查）

## 一、DML 四件套

| 操作 | 语句 | 作用 |
|---|---|---|
| 增 | `INSERT INTO ... VALUES ...` | 加行 |
| 查 | `SELECT ... FROM ... WHERE ...` | 查行 |
| 改 | `UPDATE ... SET ... WHERE ...` | 改列值 |
| 删 | `DELETE FROM ... WHERE ...` | 删行 |

DDL（CREATE / ALTER / DROP）管**结构**，DML 管**数据**。

## 二、INSERT

```sql
INSERT INTO 表名 (列1, 列2, ...) VALUES (值1, 值2, ...);
```

- 列名清单与值**按位置一一对应**，个数必须相同
- 可省略的列：自增列、有 DEFAULT 的列、可空的列。**省略的可空列自动为 NULL**
- 省略列名清单 = 必须按建表顺序给每一列都赋值（不推荐，容易错）
- 字符串 / 日期加**单引号**；数字**裸写**
- 编号类字段（isbn、学号、电话）是字符串，一律加引号

例：插入借阅记录，`return_time` 不写 = 还没还

```sql
INSERT INTO borrow_record (book_id, reader_id, loan_time)
VALUES (1, 1, '2026-10-22 10:00:00');
```

## 三、SELECT

```sql
SELECT 列 / * FROM 表
WHERE 条件
ORDER BY 列 [ASC|DESC]
LIMIT n;
```

| 部分 | 作用 |
|---|---|
| `*` 或列名清单 | 要返回哪些列 |
| `WHERE` | 留下哪些行；不写 = 全表 |
| `ORDER BY col DESC` | 按列排序，`DESC` 降序，默认 `ASC` 升序 |
| `LIMIT n` | 只返回前 n 行 |

比较运算符：`=` `>` `<` `>=` `<=` `!=`（`<>` 同义）

### NULL 规则（重点）

- `NULL` 不是值，是「未知」
- `WHERE 列 = NULL` **永远查不到行**（结果是 unknown，不是 true）
- 只能用 `IS NULL` / `IS NOT NULL`

```sql
SELECT * FROM borrow_record WHERE return_time IS NULL;  -- 还没还的记录
```

## 四、UPDATE

```sql
UPDATE 表名 SET 列 = 新值 [, 列2 = 新值2] WHERE 条件;
```

- `WHERE` 决定改哪些行；**不写 = 改全表**
- 习惯：**先用同一个 WHERE 跑 SELECT**，确认命中的行，再 UPDATE
- 改单行优先用主键 `id` 做条件

```sql
SELECT * FROM book WHERE id = 1;
UPDATE book SET isbn = '9787536692930' WHERE id = 1;
```

## 五、DELETE

```sql
DELETE FROM 表名 WHERE 条件;
```

- **不写 WHERE = 删全表数据**（表结构保留）
- 被外键引用的父表行删不掉，报 **1451**
- 删完用同条件 SELECT 复查，预期 0 行

## 六、AUTO_INCREMENT 的 id 空洞

`id` **一定不连续**，两种情况都会留洞：

1. **删除不回收**：删掉 id=2，下一个插入不会补 2
2. **失败插入也占号**：插入失败（如 1062 重复）后，自增计数器照样 +1

今日实例：

| 动作 | 得到的 id |
|---|---|
| 插张小三 | 1 |
| 插李四（phone 写错） | 2 |
| 删掉李四 | —（2 不回收） |
| 两次重复插入失败（1062） | 烧掉 3、4 |
| 重插李四 | **5** |

结论：**任何需要用 id 的地方，先查表拿真实值，不要假设 1、2、3**。

## 七、报错对照表（今日实战）

| 报错 | 原因 |
|---|---|
| `1048 Column 'loan_time' cannot be null` | 给 NOT NULL 列送了 NULL |
| `1062 Duplicate entry '2024002' for key 'reader.student_no'` | UNIQUE 列重复 |
| `1451 Cannot delete or update a parent row` | 删除被外键引用的父表行 |
| `1452 Cannot add or update a child row` | 子表引用了不存在的父 id |
| `1136 Column count doesn't match value count` | 列名个数 ≠ 值个数 |
| `1054 Unknown column 'xxx'` | 字符串漏单引号，被当成列名 |
| `1046 No database selected` | 漏了 `USE library;` |
