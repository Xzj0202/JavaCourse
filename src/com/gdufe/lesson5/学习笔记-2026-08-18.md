# 学习笔记 · 2026-08-18（接口与实现 + 栈 + 交换）

## 1. 接口 vs 实现（Java 后端最重要思想之一）

```java
Deque<Character> stack = new ArrayDeque<>();
//   类型（现成接口）   名字（你起）      真实对象类型
```

- **接口（interface）= 合同**：只规定「必须提供哪些方法」，不写实现。`Deque`、`List`、`Map`、`Set` 都是 JDK 现成的标准合同
- **实现类（class）= 干活的人**：`ArrayDeque` 用环形数组实现了 Deque 合同
- **变量名随便起；类型名必须用现成定义好的**（JDK 的或自己写的）
- 为什么左接口右实现：**换实现只改右边一行**，其余代码不碰——「面向接口编程」，Spring 后端满世界都是
- 两边同名也完全合法（`ArrayDeque<Character> s = new ArrayDeque<>();`），左边接口是社区通行习惯，读得懂即可
- 配套事实：Java 没有 C++ 的栈对象，对象一律 `new`；变量装的是**引用（地址）**

## 2. 双大括号初始化 = 反模式

```java
// 反模式：匿名子类 + 实例初始化块 → 每次调用偷偷 new 子类 → 生成 LeetCode_20$1.class
Map<Character, Character> m = new HashMap<>() {{ put(')', '('); }};
// 标准替代（JDK 9+）：
Map<Character, Character> m = Map.of(')', '(', ']', '[', '}', '{');
```

- javac 规律：**一个 .java 文件声明几个类就生成几个 .class**（`$1` = 第一个匿名类）
- **javac 只生成不清理**：改名/删类后旧 .class 是尸体，手动 del
- 判断编译生效：看**文件列表 + 时间戳**；.class 是二进制，别在编辑器里打开

## 3. Deque 栈用法

| 动作 | 方法 |
|------|------|
| 压栈 | `push(x)` |
| 弹栈 | `pop()` |
| 看栈顶 | `peek()` |
| 判空 | `isEmpty()` |

- 栈空时 `peek()/pop()` 抛异常——先 `isEmpty()` 判断
- 用 `Deque` 别用老 `Stack` 类（JDK 官方自己都推荐 Deque）

## 4. 交换：三步 temp vs XOR

```java
// 三步（推荐，可读性优先）：
char temp = s[l]; s[l] = s[r]; s[r] = temp;
// XOR（炫技，前提 l != r，否则清零；编译器把三步版优化得一样快）：
s[l] ^= s[r]; s[r] ^= s[l]; s[l] ^= s[r];
```

- Python 的 `a, b = b, a` 在 Java 不存在
- 尺子：**可读性 > 巧妙**

## 5. println(char[]) 特例

- `System.out.println(char[])` → 直接打印内容（PrintStream 对 char[] 有专门重载）
- `System.out.println(int[])` → 打印 `[I@地址`（走 Object.toString）
- 安全习惯：数组打印一律 `Arrays.toString`；char[] 是唯一例外，且你知道为什么
