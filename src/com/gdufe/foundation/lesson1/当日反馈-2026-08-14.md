## 今日命令速查
| 命令 | 作用 |
|------|------|
| `mkdir 路径` | 创建文件夹（可多层） |
| `rmdir 路径` | 删除空文件夹 |
| `del 路径` | 删除文件（不进回收站；PowerShell 一次一个，多文件用 `*.class` 通配） |
| `cd ..` / `cd 目录名` | 切换目录 |
| `ren 旧名 新名` | 改名（文件夹/文件通用） |
| `javac -d out A.java B.java` | 编译，.class 按包结构输出到 out |
| `java -cp out 包名.类名` | 运行，按类全名从类路径找 .class |

三个经典报错：
1. 找不到或无法加载主类 → 没给 -cp，或类名没写全名
2. 找不到 main 方法 → 运行了没有入口的工具类
3. 类 X 是公共的，应在名为 X.java 的文件中声明 → 类名和文件名不一致
