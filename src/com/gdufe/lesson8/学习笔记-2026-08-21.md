# 学习笔记 · 2026-08-21（字符计数 + int 溢出）

## 1. 字符当表下标（242）

```java
int[] count = new int[26];           // 建出来默认全是 0
count[s.charAt(i) - 'a']++;          // 字符编码相减得 0~25 下标
```

- `'b' - 'a'` = 1（char 是基本类型，减的是编码值，结果是 int）
- 单数组优化：第一串 ++、第二串 --，最后全 0 即异位词
- 比较 int[] 用 `Arrays.equals(a, b)`（不能用 ==，老知识点）

## 2. int 溢出（7 题）

- int 32 位：`Integer.MIN_VALUE`（-2147483648）~ `Integer.MAX_VALUE`（2147483647）
- **溢出不报错，静默绕回**：2147483647 + 1 = -2147483648
- 防御：「乘前检查」——`rev` 已超过 `MAX/10` 时，再乘 10 必溢出，提前返回 0

```java
while (x != 0) {
    if (rev < Integer.MIN_VALUE / 10 || rev > Integer.MAX_VALUE / 10) return 0;
    rev = rev * 10 + x % 10;
    x /= 10;
}
```

- 严格版还检查 `rev == MAX/10 && pop > 7` 的边界；对 int 输入，简化版已完备
- 强制类型转换：`(int) longValue`（long → int 窄化需显式 cast）

## 3. Java 负数除法/取余 ≠ Python

| 表达式 | Java（向零截断） | Python（向下取整） |
|--------|------------------|-------------------|
| `-123 / 10` | -12 | -13 |
| `-123 % 10` | -3（余数带被除数符号） | 7 |

- 好处：`while (x != 0) { rev = rev*10 + x%10; x /= 10; }` 对负数天然正确，不用单独处理符号
- 坑：`Math.abs(Integer.MIN_VALUE)` 返回的**还是负数**（2147483648 装不进 int）——别用它处理符号
