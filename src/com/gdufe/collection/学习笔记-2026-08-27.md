# 学习笔记 · 2026-08-27（继承与接口 + MyHashMap）

## 1. 继承与接口（C++ 对照速查）

| C++ | Java | 要点 |
|-----|------|------|
| `class A : public B` | `class A extends B` | 单继承 |
| 多继承 | `implements I1, I2` | 接口多实现 |
| virtual | 不写（默认虚） | 非 static/final 方法都动态绑定 |
| `= 0` 纯虚函数 | `interface I { void f(); }` | 接口≈纯虚函数集合 |
| `B::f()` | `super.f()` | 显式调父类 |
| override（可选） | `@Override`（编译期检查） | 写错签名直接报错 |
| 无 | Object 是所有类的祖宗 | toString/equals/hashCode |

- 实现接口必须实现它的**全部**方法，漏一个编译错「不是抽象的」
- 构造器不继承；子类构造器默认调父类无参构造

## 2. 多态三要素（Shape 示例）

```java
Shape[] shapes = { new Circle(2), new Rectangle(3, 4) };
for (Shape s : shapes) s.area();   // 各自按自己的实现算
```

合同（接口）→ 实现（implements）→ 运行时按真实身份执行。与 Deque 接 ArrayDeque 同构。

## 3. MyHashMap 全景（7 节注释版在 collection 包）

```
table（桶数组，容量 16/32/64... 永远 2 的幂）
  └─ 每个格子：链表头（拉链法解决冲突）
```

| 动作 | 核心 |
|------|------|
| 定位桶 | `key.hashCode() & (table.length - 1)`；null 键 → 桶 0 |
| put | 同 key 覆盖（Objects.equals 比内容）；否则头插 + size++；超 0.75 负载 → resize |
| get | 定位桶 → 链表遍历 equals 比对 |
| remove | 前驱指针跨过被删节点（prev.next = n.next） |
| resize | 新数组 ×2 → 每个节点按新长度重算下标重挂（**必须 rehash：下标依赖长度**） |

- 泛型数组不能直接 new（擦除）→ 强转 + @SuppressWarnings("unchecked")
- 头插 vs 尾插：JDK 8 起尾插，因为头插在多线程扩容时会成环（阶段 1 多线程讲）
