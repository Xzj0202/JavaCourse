# 学习笔记 · 2026-08-26（ArrayList 机制 + 手写 MyArrayList + 异常）

## 1. ArrayList 真身（人话版）

```java
Object[] elementData;   // 装元素的数组（长度=容量）
int size;               // 实际元素数（<= elementData.length）
int modCount;           // 结构改动计数（fail-fast 用）

public boolean add(E e) {
    if (size == elementData.length) grow();   // 满了才扩容
    elementData[size++] = e;
    return true;
}
// grow：new 一个 1.5 倍新数组 → 复制旧元素 → elementData = 新数组（换指向！）
```

- 为什么必须复制：**数组定长**，「原地变大」不存在
- size（坐了几个人）≠ elementData.length（买了几个座）
- elementData 是 Object[]：Object 是所有类的祖宗，「万能货架」；不用 E[] 因为泛型擦除

## 2. remove = 搬家

```java
E num = (E) elementData[index];
for (int i = index; i < size - 1; ++i) elementData[i] = elementData[i + 1];  // 整体前挪
elementData[--size] = null;   // 清尾：让 GC 收走旧引用
return num;
```

## 3. fail-fast

- modCount 每次 add/remove +1；迭代器记下出生时的值，遍历时对不上就抛 ConcurrentModificationException
- 理念：宁可当场炸，不带着脏数据继续跑；遍历时删除 → 用迭代器的 remove

## 4. 异常基础

```java
throw new IndexOutOfBoundsException("index: " + index + ", size: " + size);
```

- throw = 拉警报：方法立刻终止，警报向上传；没人接 → 程序终止 + 红字
- 红字读法：第一行 = 异常类型 + 消息；`at ...` 行 = 案发路线（谁调了谁，在哪一行）
- 为什么抛：fail-fast——边界错是调用方 bug，必须当场炸
- try/catch = 接警报（阶段 1 正式学）

## 5. 手写踩坑清单（MyArrayList 第一版 9 编译错 + 2 逻辑错）

| 坑 | 正解 |
|----|------|
| 数组用 .get/.put | 数组**没有方法**，用 `[i]`（Map 才有 get/put） |
| `int(x)` | Java 转型：`(int) (x)` |
| grow 造了新数组不赋值 | 最后必须 `elementData = newData;`（换指向） |
| add 的 else 里放元素 | 扩容与否都要放：放行必须在 if 外面 |
| 块内声明的变量块外用 | 变量作用域：声明提到块外 |
| 边界判断 `index > 0` | 应为 `index >= 0`；不合法要抛异常而非静默 |
| get/remove 缺 return | 每条路径都要有返回值 |
