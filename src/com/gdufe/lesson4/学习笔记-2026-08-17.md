# 学习笔记 · 2026-08-17（String 不可变 + == 与 equals）

## 1. String 不可变（immutable）

- Java 的 String 一旦创建，**内容永远不能改**
- 看似「修改」的方法（toLowerCase / substring / replace）都是**造新字符串**还给你，原串不动
- 所以 `s.charAt(i) = xxx` 两层都错：语法上不能给方法返回值赋值；概念上 String 不可原地改
- 报错长相：`需要: 变量 / 找到: 值` —— 等号左边必须是「能装东西的盒子」（变量）
- 想「改」字符串 = 重建：`s = s.substring(0, i) + 新字符 + s.substring(i + 1);`
- 类比：String 是刻好的石碑，想换内容就重新刻一块
- （Python 字符串同样不可变，`s[0] = 'x'` 在 Python 里也报错）

## 2. == 和 equals 的分界

| | 基本类型 | 引用类型 |
|---|---|---|
| 是哪些 | `int` `char` `double` `boolean` `long` `float` `short` `byte` | 其余全是：String、数组、所有类对象 |
| 变量装的是 | 值本身 | 地址（门牌号） |
| `==` 比什么 | 值 | 地址 |
| 比内容 | `==` 就行 | `.equals()` |

- **口诀**：类型名首字母**小写** → `==` 比内容；首字母**大写** → 比内容用 `.equals()`
- 两个内容相同但地址不同的 String：`==` → false，`.equals()` → true
- `==` 有时「碰巧」true（字面量共享地址），有时对有时错比永远错更坑
- 预告：`Integer` 等包装类也是引用类型，以后做包装类题时再遇

## 3. 报错对照表新增

| 报错 | 含义 | 排查 |
|------|------|------|
| ClassNotFoundException（找不到或无法加载主类 + 原因行） | java 在 classpath 里没找到对应的 .class | 先看 out 里 .class 生成了没；没有 → javac 其实失败了，重编译看红字 |
| 需要: 变量 / 找到: 值 | 给「值」赋值（如方法调用结果） | 等号左边换成变量；字符串用重建法 |
| 缺少返回语句 | 某条路径没有 return | 方法末尾补兜底 return |

排查口诀：**运行报「找不到类」先查编译，编译报错先看行号。**

## 4. 双指针回文串（125 最优解）

```java
for (int i = 0, j = s.length() - 1; i < j;) {
    if (!Character.isLetterOrDigit(s.charAt(i))) { ++i; }
    else if (!Character.isLetterOrDigit(s.charAt(j))) { --j; }
    else if (Character.toLowerCase(s.charAt(i)) == Character.toLowerCase(s.charAt(j))) { ++i; --j; }
    else { return false; }
}
return true;
```

- 左右指针相向而行，跳过非字母数字；char 是基本类型，`==` 比值合法
- O(n) 时间 O(1) 空间；对比 substring 重建版 O(n²)
- `for` 的第三个位置可以空着（`for (;;) { }` 写法合法）

## 5. 字符工具

- `Character.isLetterOrDigit(c)` —— 判断字母或数字（替代裸 ASCII 数字 65~90）
- `Character.toLowerCase(c)` / `toUpperCase(c)` —— 返回**新**字符（char 是基本类型，返回的是值）
