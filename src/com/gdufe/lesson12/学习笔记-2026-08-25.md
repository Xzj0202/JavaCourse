## 1. 最长公共前缀（14）

**substring 版**（String 不可变 → 每次砍都造新串）：
```java
String prefix = strs[0];
for (int i = 1; i < strs.length; ++i) {
    while (!strs[i].startsWith(prefix)) {
        prefix = prefix.substring(0, prefix.length() - 1);
        if (prefix.isEmpty()) return "";
    }
}
return prefix;
```

**StringBuilder 版**（可变 → 原地砍，效率更高，本次采用）：
```java
StringBuilder prefix = new StringBuilder(strs[0]);
for (int i = 1; i < strs.length; ++i) {
    while (strs[i].indexOf(prefix.toString()) != 0) {   // 不在开头（含找不到=-1）
        prefix.deleteCharAt(prefix.length() - 1);
        if (prefix.isEmpty()) return "";
    }
}
return prefix.toString();
```

- 新 API：`startsWith` / `indexOf` / `substring(0, n)` 左闭右开 / `StringBuilder.deleteCharAt`
- 关键：前缀砍空立刻 return，防死循环
- 死代码要删：注释掉的旧版本会让读者困惑

## 2. 回文数三解法（9）

| 解法 | 思路 | 特点 |
|------|------|------|
| 字符串版 | 转 String 双指针比 | 最直观 |
| 半反转版 | `while (x > rev) rev = rev*10 + x%10, x/=10`，奇偶两种判定 | 避开 int 溢出（呼应 7 题） |
| 首尾比较版（本次采用） | `div` 算最高位除数，比完首尾剥一层 `x = (x % div) / 10`，`div /= 100` | 不反转、无溢出风险 |

- 共同拦截：负数 false；末位 0 的数 false（0 本身除外）
