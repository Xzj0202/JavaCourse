## 1. ListNode 类（TreeNode 的单链版）

```java
public class ListNode {
    int val;
    ListNode next;
    ListNode(int x) { val = x; }
}
```

## 2. 三指针反转模板（206）

```java
ListNode pre = null, cur = head;
while (cur != null) {
    ListNode next = cur.next;  // ① 先存下家，防止断链
    cur.next = pre;            // ② 掉头
    pre = cur;                 // ③ 三指针整体前移
    cur = next;
}
return pre;                    // cur 已是 null，pre 才是新头
```

**顺序是生死线**：先存 next，再掉头。

## 3. 哨兵节点（21，链表面试核心技巧）

```java
ListNode dummy = new ListNode(-1);  // 假头占位，值没人看（0/-1 都行）
ListNode cur = dummy;               // cur = 队尾指针
// …循环里：cur.next = 选中的; cur = cur.next;
cur.next = list1 != null ? list1 : list2;  // 剩余整条直接接上
return dummy.next;                  // 扔掉假头
```

- 解决什么：不用区分「插第一个节点」和「插后面」两套写法
- 类比：排队时的占位员，最后走人
- 空链表天然扛住

## 4. 链表遍历打印

for (ListNode p = head; p != null; p = p.next) {

## 5. 传参机制（今天讲透的「为什么」）

> **传参 = 把变量里装的东西复制一份给参数。**

| 传的 | 副本是 | 方法里改 | 外面 |
|------|--------|----------|------|
| 基本类型（int/char） | 值 | 改的是值副本 | 不变 |
| 引用类型（数组/对象） | 地址 | 地址指向同一个对象，改内容 | 变了 |
| 引用类型 | 地址 | 改**指向**（s = new xxx） | 不变 |

**改内容有效，改指向无效**——改指向只是改了副本的地址。
