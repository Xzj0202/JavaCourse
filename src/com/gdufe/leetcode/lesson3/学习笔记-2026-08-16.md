## 1. Java 刷题模板（从今往后每题照此办理）

```java
package com.gdufe.lessonN;

import java.util.xxx;   // 用到什么导什么（显式导入）

public class 题名 {
    // LeetCode 题号 题目描述
    public 返回类型 方法名(参数...) {   // 签名照抄 LeetCode，一个字符不改
        // 你的翻译
    }

    public static void main(String[] args) {
        题名 solution = new 题名();     // LeetCode 方法不是 static，要先 new
        System.out.println(solution.方法名(测试数据));  // 本地验证
    }
}
```

**三条铁律**：
1. **文件名 = 类名**（public 类），否则报「类 X 是公共的，应在名为 X.java 的文件中声明」
2. **方法签名照抄 LeetCode**——因为这段代码最后要贴回 LeetCode 提交
3. **本地验证走命令行**：`javac -d out src/com/gdufe/lessonN/题名.java` → `java -cp out com.gdufe.lessonN.题名`

## 2. 今天的新语法

| 语法 | 写法 | 说明 |
|------|------|------|
| 数组字面量 | `int[] nums = {1, 2, 2, 1};` | 创建并初始化数组 |
| 增强 for | `for (int x : arr)` | 冒号读作「在…里」，遍历每个元素 |
| 打印数组 | `Arrays.toString(arr)` | 直接 println 数组会打印地址 `[I@xxx` |
| 集合 | `new HashSet<Integer>()` / `new ArrayList<Integer>()` | Python 的 set / list 对应物 |
| 显式导入 | `import java.util.HashSet;` | 用到什么导什么，比 `import java.util.*;` 更规范 |

## 3. Python → Java 翻译对照表（累积版）

| Python | Java |
|--------|------|
| `set()` / `list()` | `new HashSet<>()` / `new ArrayList<>()` |
| `x in s` | `s.contains(x)` |
| `for x in s` | `for (int x : s)` |
| `print(list)` | `System.out.println(Arrays.toString(arr))` |
| 变量不用声明 | 变量必须声明类型：`int x = 0;` |
| 数组不定长 | 数组定长；不定长用 ArrayList |

## 4. 去重两种写法（349 亲历）

```java
// 巧妙版：remove 返回「原来有没有」，一石二鸟
if (set.remove(x)) list.add(x);

// 清晰版：先判断再拿走，一眼看懂（推荐）
if (set.contains(x)) { list.add(x); set.remove(x); }
```

工程取舍：**牺牲一点巧妙，换取一目了然**。

## 5. 位运算 `n >>= 2`

- 正数右移 2 位 = 除以 4；`>>` 是算术右移（带符号），对负数不成立（负数要先用边界拦截）
- 「位运算更快」：编译器会把 `n /= 4` 自动优化成移位，两种写法速度一样
- 学位运算的真正价值：**读得懂别人写的代码**（JDK 源码遍地都是）

## 6. ren 改名细节

- `ren` 只认**当前目录**：要么 `cd` 进文件所在文件夹，要么写相对路径 `ren src/com/gdufe/lesson3/A.java B.java`
- 新名字**要带扩展名**
- 改名三同步：**文件名 = 类名 = 注释里的题号**，三处一起改
- 改完清理旧编译产物：`del out/com/gdufe/lesson3/旧名.class`（尸体不入库，但也不该留着）

## 7. 编译红字排查流程

1. 看红字里报的**行号**和「找不到符号」后面的**名字**
2. 名字是类 → 多半 import 缺失（去文件顶部补 import）
3. 名字是变量/方法 → 多半拼写错（对照声明处检查）
