## 1. 类定义基础（TreeNode 课）

```java
public class TreeNode {
    int val;             // 字段：每个对象自己的数据
    TreeNode left;       // 字段类型可以是类自己 → 递归结构（节点里含节点）
    TreeNode right;

    TreeNode() {}                                          // 无参构造：字段保持默认（int→0，引用→null）
    TreeNode(int val) { this.val = val; }                  // 参数与字段同名时：裸 val = 参数，this.val = 字段
    TreeNode(int val, TreeNode left, TreeNode right) {     // 方法重载：参数列表不同，new 时自动选
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

- **构造方法**：没有返回类型、名字 = 类名，`new` 时自动执行
- **`this`** = 当前对象；参数与字段同名时用它区分
- **重载（overload）**：同名方法参数列表不同，编译期按参数个数/类型自动选择
- 类名 = 文件名（public class）
- 同包的类**不需要 import**（import 是引外援）

## 2. 多文件编译（今天的墙）

```
javac -d out src/com/gdufe/lesson6/TreeNode.java src/com/gdufe/lesson6/LeetCode_100.java
javac -d out src/com/gdufe/lesson6/*.java          # 通配符版（javac 自己认识 *）
```

- **规律**：你的类 A 用到类 B → A、B 源文件**都递给 javac**
- javac 只在你给的文件 + 当前目录的包路径里找依赖；不会翻 out 里的旧 .class
- 报错长相：`找不到符号: 类 XXX` × N
- 这就是阶段 0 验收第一条（多文件编译运行）；也是 Maven 存在的理由——类多了以后手工列文件会烦死

## 4. 树递归模板

**104 最大深度**：
```java
return root == null ? 0 : Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
```

**100 相同的树——null 判断顺序（核心坑）**：
```java
if (p == null && q == null) return true;      // 先：都空 → 相同
else if (p == null || q == null) return false; // 再：一空一不空 → 不同
else if (p.val != q.val) return false;         // 再：值不同 → 不同
else return isSameTree(p.left, q.left) && isSameTree(p.right, q.right);  // 最后递归，Python and → Java &&
```

顺序反了 → NullPointerException。

## 5. 基本类型 vs 引用类型（抽查纠错）

- 基本类型只有 8 个：int / char / double / boolean / long / float / short / byte
- **char 是基本类型；char[] 是引用类型**（数组装地址）
- 传参一律传「值的副本」：
  - 传基本类型 → 副本是值，方法里改不动外面
  - 传引用类型 → 副本是地址，地址指向同一对象，原地改生效
