## 1. XOR 交换的前提：位置不同，不是值不同

| 场景 | 结果 |
|------|------|
| 两个格子，值相同（i≠j，都存 1） | ✅ 安全交换 |
| **同一个格子**（i==j，swap(nums,0,0)） | ❌ `x ^= x` → 0，值被毁 |

- 本质是**别名（aliasing）**问题：同一个内存位置同时扮演 a 和 b，第一句就把数据源头清了
- C++ 同款：`swap(a, b)` 若 a、b 引用同一变量，引用版 XOR swap 同样炸
- 修法：`if (i == j) return;` 守卫，或直接用三步 temp（**无条件安全**）
- 工程结论：巧妙写法都有隐藏前提，前提破了就是 bug；朴素写法没有前提

## 2. 双指针 + 交换模板（283 移动零）

```java
int p = 0;                                  // 慢指针：下一个非零该放的位置
for (int i = 0; i < nums.length; ++i) {     // 快指针：扫全数组
    if (nums[i] != 0) swap(nums, p++, i);   // 交换而非覆盖（覆盖丢数据）
}
```

## 3. 滚动变量迭代（70 爬楼梯）

```java
int i = 0, j = 1;                 // 只保留前两项，O(1) 空间
for (int k = 0; k < n; ++k) {
    j += i;                       // j = 前两项之和
    i = j - i;                    // 减法还原旧 j——省掉临时变量
}
return j;                         // f(n) = f(n-1) + f(n-2)
```

- 递归 → 记忆化 → 迭代 是 DP 三步阶梯；熟练后可直接写迭代
- 减法更新没有 XOR 的别名坑（i/j 恒为两个变量）

| 形态 | 时机 | 例子 |
