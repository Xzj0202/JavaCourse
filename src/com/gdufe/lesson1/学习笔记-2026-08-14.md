# 学习笔记 · 2026-08-14（第一课：javac -d 与 java -cp）

## 1. Java 程序是怎么跑起来的

写代码 → 翻译 → 执行，三步：

| 步骤 | 命令 | 输入 | 输出 |
|------|------|------|------|
| 翻译（编译） | `javac` | 你写的 `.java` | 电脑能执行的 `.class` |
| 执行（运行） | `java` | 类全名 | 程序输出 |

- `.java` 是给人看的源码，`.class` 是翻译后的字节码
- VSCode 的「运行」按钮背后就是这两条命令，只是替你藏起来了

## 2. package（包）

- 文件第一行 `package com.gdufe.lesson1;` 声明这个类属于哪个包
- **类全名 = 包名.类名**，例如 `com.gdufe.lesson1.Main`
- **目录对应规则**：包 `com.gdufe.lesson1` ↔ 文件夹 `src/com/gdufe/lesson1`
  - ⚠️ **src 是容器，不算进包名**——曾踩坑：写成 `package src.com.gdufe.lesson1;` 是错的
- 惯例：包名 = 域名倒写（gdufe = 广财英文缩写；阿里是 com.alibaba）
- 包声明和文件位置不一致时，**编辑器行为会异常**（第一课亲历：文件放错目录导致格式化失灵）

## 3. javac -d

```
javac -d out src/com/gdufe/lesson1/Calculator.java src/com/gdufe/lesson1/Main.java
```

- `javac`：翻译器
- `-d out`：d = destination（目的地），告诉它翻译结果放哪；会**自动按包结构建子目录** → `out/com/gdufe/lesson1/*.class`
- **不加 `-d`**：`.class` 直接落在源码旁边，和 `.java` 混在一起（实验 2 亲历）

## 4. java -cp

```
java -cp out com.gdufe.lesson1.Main
```

- `java`：执行器
- `-cp out`：cp = classpath（类路径），告诉它**去哪找 .class**
- 最后写**类全名**，记住三个「不」：不带 `.class` 后缀、不带目录斜杠、不写 `out` 前缀
- **不加 `-cp`**：只在当前目录找 → 报「找不到或无法加载主类」（实验 1 亲历）

## 5. 三个经典报错 → 原因 → 解法

| 报错 | 原因 | 解法 |
|------|------|------|
| 找不到或无法加载主类 | 没给 -cp；或类名没写全名 | 补 `-cp out`，类名写 `包名.类名` |
| 找不到 main 方法 | 运行了没有入口的工具类 | 运行带 main 的那个类 |
| 类 X 是公共的，应在名为 X.java 的文件中声明 | 类名和文件名不一致 | 文件名 = public 类名 |

## 6. 终端命令速查

| 命令 | 作用 | 注意 |
|------|------|------|
| `mkdir 路径` | 建文件夹（可多层） | 成功静默无输出；失败一定红字 |
| `rmdir 路径` | 删**空**文件夹 | 里面有文件就删不掉 |
| `del 路径` | 删文件（不进回收站） | PowerShell 里是 Remove-Item 别名，**一次只收一个路径**；多文件用通配符 `*.class` |
| `cd ..` / `cd 目录名` | 切换目录 | `..` = 上一层 |
| `ren 旧名 新名` | 改名（文件/文件夹通用） | **旧名在前**；文件夹被进程占用时报「另一个进程正在使用」 |

## 7. 斜杠 / 和 \

- Windows 上两个都行，效果一样（DOS 时代 `/` 被拿去做命令选项，路径才用 `\`；Linux 一直用 `/`）
- **建议以后统一用正斜杠 `/`**：Linux/Mac/WSL 只认正斜杠，迟早要进服务器环境

## 8. 运行按钮 vs 终端

- 三角形按钮 = Code Runner 插件，内部命令：`cd $dir && javac $fileName && java $fileNameWithoutExt`
- 它只适合**没有包名、单个文件**的刷题代码；带包名的类必须用「包名.类名」全名运行，按钮只会用裸类名，跑不了
- 规则：**课程工程代码一律终端手敲命令；刷题单文件可以继续用按钮**

## 9. VSCode 格式化（已配置好）

- `formatOnSave`：Ctrl+S 保存时自动整理全文
- `formatOnType` + `java.format.onType.enabled`：敲 `;` `}` 回车的瞬间自动整理（VSCode 和 Java 扩展双保险）
- 灰蒙蒙的 `a:` `b:` 是 **inlay hints 参数名提示**，不是真实字符，删不掉、不参与选中
- 格式规范：参数之间空格 `(int a, int b)`；运算符两侧空格 `a + b`
